# Numerical port validation — 2026-09-21

The default solver has since been upgraded to [matrix-free RV](RV.md).
All 18 configurations pass again, with maximum absolute array difference
2.423e-12 from R and 2.480e-12 from the previous dense C++ outputs. See the
[updated benchmark](BENCHMARK-MATRIX-FREE.md); the timing figures below
document the first dense port.

Reference: unchanged R PhylteR 0.9.12, revision
`4d74241169be3882da9d5f08da47bd40604764eb`, independently installed in the
parent repository's `.audit/reference-lib`. The optimized R package is also
available in `.audit/candidate-lib`. Data: bundled Carnivora, 125 genes,
53 taxa. See fixture provenance for the original data checksum.

## Scientific comparison

The executable was compared against the original R implementation in 18 cases:
default matrices, tree input, nodal distances, mean normalization, no distance
normalization, no islands, column WR normalization, no WR normalization,
alternative gene threshold, missing taxa, discarded genes, initial-only,
no detected outliers, rejected proposals, indefinite distance spectra,
never-co-occurring taxa, support filtering, and nodal support filtering.

All cases passed:

* exact gene/species outlier IDs **and order**;
* exact removed cell indices, including imputed-only cells;
* exact discarded pairs, gene order, taxon order and accepted-state count;
* quality, weights, RV, compromise, WR and coordinate Gram matrices at **every
  accepted state**, compared with tolerance `1e-8 * max(1, max(abs(reference)))`.

The largest observed absolute numerical difference was
**3.836930773104541e-13**. This is a measurement on these fixtures, not a guarantee
for every dataset or BLAS implementation.

Default Carnivora: **94 outlier pairs**, **11 states**, final quality
**0.944259987303**. Negative spectra are selected by eigenvalue magnitude before
algebraic sorting, matching RSpectra. Coordinate comparisons use Gram matrices
because eigenvector signs are arbitrary.

## Standalone tests

CTest includes:

1. Core numerical values from R, overflow/invalid inputs, quoted and bounded
   Newick parsing, multiple trees, nodal distances and imputation.
2. Frozen Carnivora reference (no R runtime), medcouple samples including
   constants/ties and both sides of the reflection cutoff, and ten clustering
   tie fixtures generated by R.
3. CLI input validation.
4. CLI Carnivora output, overwrite protection, invalid numeric parameters and
   byte-identical serial/four-thread scores and outlier tables.

AddressSanitizer, UndefinedBehaviorSanitizer and LeakSanitizer are used in the
debug build. LeakSanitizer requires execution outside the local ptrace sandbox;
the ordinary release tests run inside it.

## Local timing and memory

The newer [fresh-process and scaling benchmark](BENCHMARK.md) extends these
measurements to 500 and 1,000 genes. It found that the initial dense C++ port became
slower than the original R at 1,000 genes, despite continuing to use less RAM.

Five runs, one RV thread, sequential system BLAS/LAPACK, release C++ build:

| Implementation | Median elapsed time |
| --- | ---: |
| Original R reference | 1.110 s |
| Previously optimized R | 0.431 s |
| Native C++ CLI | 0.276–0.279 s |

R timing measures the analysis after loading the package. C++ timing includes
process startup, Newick reading and compact TSV output. There is no diagnostic
matrix output in these timings. The native CLI is approximately **4.0×** faster
than the original R analysis and **1.5×** faster than the optimized R analysis
on this small dataset. These ratios do not predict large-dataset performance.

Peak process RSS from separate single-analysis runs:

| Implementation | Peak RSS |
| --- | ---: |
| Original R reference | 294652 KiB |
| Previously optimized R | 290448 KiB |
| Native C++ CLI | 17316 KiB |

The R measurements include the interpreter and loaded dependencies; the native
measurement includes its numerical libraries. The reduction is not solely an
algorithmic memory improvement. Dense matrices and the full RV matrix remain.

Reproduce timings with `tests/benchmark.R`, selecting each R installation with
`R_LIBS`. Local detailed outputs are in `build/benchmark-*.txt`,
`build/rss-*.txt`, and `build/reference-validation-final/` (ignored).

## Distribution checks

The local Linux executable and CPack archive are built and tested. The archive
bundles numerical and compiler runtime libraries, while relying on host glibc.
It is not a broadly portable public release built on an older Linux baseline.

The Conda recipe metadata renders successfully with conda-build; a complete
Conda package build/publication has not been performed. The future standalone
repository includes a Linux/macOS/Windows build workflow, which has not been
executed on remote runners. macOS/Windows release archives remain pending.

## Remaining stages

Matrix-free RV is now implemented. Packed symmetric storage and an approximate
fast mode remain pending. They must retain the dense implementation
and the R reference as independent comparators. In particular, the legacy
never-co-occurring-taxon fallback can produce asymmetric matrices, which must
be accounted for before using symmetric-only storage.
